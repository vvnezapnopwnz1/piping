# Track 11 Demo Lite — deferred items

Track 11 Demo Lite exposes two client-side project snapshot downloads: Fabrication Progress XLSX and Test Pack RFT Pursuit PDF. They are a demo close-out artifact, not a documents subsystem or handover evidence.

## Not delivered

### Durable artifacts and history

- `generated-documents` private bucket and its RLS policies;
- `document_runs` lifecycle, parameters, actor, checksum and source timestamp;
- stored source snapshots, history and re-download;
- server-side/Edge Function generation.

### Other reports and forms

The UI deliberately omits every other legacy report card: `RPT-F-002`, `RPT-F-003`, `RPT-F-004`, `RPT-E-001`, `RPT-E-002`, `RPT-E-003`, `RPT-N-001`, `RPT-N-002`, `RPT-T-002`, and `RPT-T-003`.

QC-13, W-24, W-23, Examination Request, Line Check, Item Clearance, Blinding and Reinstatement remain outside this slice. Existing Track 10 printable HTML remains the only available presentation for its workflow requests.

### Handover scope

- Test Pack dossier/handover bundle;
- audit export for Project Admin/System Admin;
- reproducible, timestamp-bound report artifacts.

## Accurate product claim

The two Lite files are generated in the operator's browser from the current RLS-authorized project data. They can demonstrate data export, but cannot be presented as durable, reproducible, or traceable project handover documents.
