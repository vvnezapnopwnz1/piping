# Track 08 deferred items

Track 08 deliberately closes the simplest manual-aligned online workflow. The following items
are outside its completion claim and must not be implied by the demo UI.

## Offline PWA and synchronization

- installable PWA/service worker;
- encrypted scoped device cache;
- IndexedDB offline scan queue;
- reconnect batch with per-item accepted/rejected/conflict results;
- conflict-resolution UI for revision or scope changes.

The current scanner path is an administrator-applied file import that reuses the same database
invariant and source-key idempotency as ordinary commands. It is not an offline-sync claim.

## Device revocation

Current Track 08 validates active project device assignment for every recorded event and shows
assigned/unassigned inventory. A revocation protocol for already cached offline data belongs to
the future offline contract and is not simulated as battery, connectivity or health telemetry.

## Managed image ingestion

Spool and design-area panels explicitly report that no managed image is available. Storage
bucket policy, accepted media types, revision ownership, retention and ingestion are deferred;
the current UI does not fabricate a map or attach arbitrary external images.
