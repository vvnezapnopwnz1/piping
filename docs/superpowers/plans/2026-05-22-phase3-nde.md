# Phase 3 — NDE Management (flagship phase)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the deep-domain NDE gaps from roadmap_v3 Phase 3 slices 3.1–3.6 — the **flagship phase** of PipeQC. This phase delivers the auto-cascade that no Excel-based competitor can replicate: per-weld Reject with **defect code** → auto-creates an **`-R1` joint** in the NDE100 category → flips remaining welds to **tracer T1** → on 2nd-level tracer or 4-rejection threshold, **Penalty Shoot** auto-flips all remaining welds to SS. This is the demo-defining moment per CC-N4 (presentation_findings.md #4 verbatim) and the highest-leverage slice in the entire roadmap.

**Critical context discovered during code audit:**
- **Slice 3.1 partial credit.** `components/nde/receive-results-panel.tsx:114` already has a real per-weld Accept/Reject radio + rework code dropdown — NOT bulk-accept as roadmap_v3 states. The actual gap is **Defect Code + Location of Defect** (per nde_inspector.md B3 + presentation #4 line 785). The current `rework code` field is a *fix action* taxonomy (Grind & re-weld, Cut-out) — different concept from a *defect code* (POR / CRK / LOF / SLG / UNC / INC) which describes what was found. Both must coexist.
- **Tracer T1/T2 exists, but second-level cascade is missing.** `lib/nde-status.ts` has a `TracerSelection` type with `level: "T1" | "T2"` only. `store/batches-store.ts:492 setTracerSelections` only ever assigns T1 then T2. There is **no T1-1 / T1-2 / T2-1 / T2-2** logic — needed for Penalty Shoot trigger per #4.
- **`hasNde100Requirement` is display-only.** It returns a boolean badge "NDE 100 required" if rejected + rejected-tracers ≥ 4 (`lib/nde-status.ts:39`). It does **NOT** auto-flip remaining welds to SS, does **NOT** add remaining batch welds as new SS rows, does **NOT** flip the welder's status to SS. Penalty Shoot has the badge but no behavior.
- **R1 joint auto-creation is completely missing.** Searched lib/, store/, components/: zero matches for `createR1`, `createReworkJoint`, `-R1` suffix logic. On reject the rejected weld goes back to fabrication via `markForRework`, but no **new `J-XXXX-R1` joint** is created in the NDE100 category.
- **NDE Matrix CRUD is live** (`store/admin-store.ts:584` from Phase 0). `matrixRef` field exists on `NdeBatch`. Wire Penalty Shoot trigger to read sampling % from this matrix (currently it doesn't).
- **No joint-level Examination History view.** Batch-level history exists (`batch-detail-panel.tsx` History tab); joint-level timeline (original → R1 → R2 → R3 with who/when/result/defect codes per cycle) does not.
- **Defect Code referential does not exist** (REWORK_CODES exist; DEFECT_CODES do not). Per nde_inspector.md verbatim: POR / CRK / LOF / SLG / UNC / INC / OTH. Add to `lib/engineering-references.ts`.
- **NDE Matrix sampling % already editable** (`admin-store.ts` `addNdeRule` / `updateNdeRule`) — confirms roadmap_v3 Open Q "0.4 NDE Matrix CRUD" is closed. Penalty Shoot can read sampling % directly from `useNdeMatrix()`.

**Architecture:**
- Extend `lib/nde-status.ts` `TracerSelection.level` to include `"T1-1" | "T1-2" | "T2-1" | "T2-2"` (second-level cascade).

  1. For each Rejected weld: create a sibling `J-XXXX-R1` weld record in `welds-store` (status = `Pending NDE`, `parentJointId`, category = `NDE100`).
  2. Add that R1 joint to the SAME batch as a new row with status = `Awaiting NDE` (per #4: "new joint goes into the 100% NDE category").
  3. For all non-rejected welds in batch: flip to T1 tracer via `setTracerSelections`.
  4. Check Penalty Shoot trigger: if `rejections + 2ndLevelTracers ≥ 4` OR `any 2nd-level tracer exists` → auto-add all remaining batch-eligible welds (from same welder × NDE category in the welds-store) to the batch as new rows with code `SS`. Also flip welder.status to `SS` in welds-store.

Linked from weld-detail-panel and batch-detail-panel weld rows.
- Add `app/nde/dashboard/page.tsx` — dedicated NDE dashboard with: acceptance rate trend (last 30 days), per-welder rejection count, per-subcontractor performance, active Penalty Shoot indicator.
- **NDE100 dual state machine** is satisfied implicitly: an `-R1` joint with `category === "NDE100"` is always treated as 100%. We do NOT introduce parallel S/SS vs H/HS enums — we keep one enum on `NdeBatchWeld.result` and add a `category: "NDE10" | "NDE20" | "NDE100"` field. ## Task 3 — NDE cascade engine: pure-function library (Slice 3.2 + 3.3 + 3.4 core logic)

**Files:**
- Create: `lib/nde-cascade.ts`

**What this builds:** A pure-function module that contains ALL the cascade rules — R1 joint creation, tracer assignment, second-level tracer cascade, Penalty Shoot detection. Pure functions only so they're testable in isolation; store wiring happens in Task 4.

The cascade rules (verbatim from presentation_findings.md #4):

1. **On Reject:** create `J-XXXX-R1` joint with `category: "NDE100"` and `parentWeldId: original.id`. Add it to the SAME batch with status = `Awaiting NDE` (per #4 line 786-789).
2. **On Reject:** all non-rejected welds in batch → flip to **T1 tracer** (per #4 line 791).
3. **On T1 tracer reject:** spawn **T1-1 + T1-2** (level-2 tracers) per #4 line 796. Similarly T2 → T2-1/T2-2.
4. **Penalty Shoot trigger** (per #4 lines 802-806): **OR (a)** any 2nd-level tracer exists (T1-1 / T1-2 / T2-1 / T2-2); **OR (b)** 4 joints rejected in batch → ALL remaining welds in batch flip to SS, batch status flips to "Awaiting NDE".

- [ ] **Step 1: Create `lib/nde-cascade.ts`**

```typescript
"use client"

import type { NdeBatch, NdeBatchWeld, WeldResultInput } from "@/store/batches-store"
import type { WeldJoint } from "@/lib/weld-data"
import type { TracerSelection } from "@/lib/nde-status"

export interface CascadeOutcome {
  r1JointsToCreate: Array<{
    parentWeldId: string
    parentJointNo: string
    spoolNo: string
    isoNo: string
    welder: string
    dwirNo: string
    materialType: string
    diaInch: string
    wpsNo: string
    defectCode?: string
    defectLocation?: string
  }>
  tracerAssignments: Array<{
    sourceRejectedWeldId: string
    candidateWeldIds: string[]
    level: TracerSelection["level"]
  }>
  penaltyShootTriggered: boolean
  penaltyShootReason: "FOUR_REJECTIONS" | "SECOND_LEVEL_TRACER" | null
  ssEligibleWeldIds: string[]   // welds same welder × NDE category, not yet in batch
}

/**
 * Decide what cascade actions should happen given a batch + new results.
 * Pure function — no store access, no side effects.
 */
export function processRejections(
  batch: NdeBatch,
  results: WeldResultInput[],
  allShopWelds: WeldJoint[],
  allFieldWelds: WeldJoint[],
): CascadeOutcome {
  const sourceWelds = batch.source === "field" ? allFieldWelds : allShopWelds
  const rejectedResults = results.filter((r) => r.result === "Rejected")

  // 1) R1 joints to create — one per rejected weld
  const r1JointsToCreate: CascadeOutcome["r1JointsToCreate"] = rejectedResults.flatMap((r) => {
    const batchWeld = batch.welds.find((w) => w.id === r.weldId)
    if (!batchWeld) return []
    return [
      {
        parentWeldId: r.weldId,
        parentJointNo: batchWeld.jointNo,
        spoolNo: batchWeld.spoolNo,
        isoNo: batchWeld.isoNo,
        welder: batchWeld.welder,
        dwirNo: batchWeld.dwirNo,
        materialType: batchWeld.materialType,
        diaInch: batchWeld.diaInch,
        wpsNo: batchWeld.wpsNo,
        defectCode: r.defectCode,
        defectLocation: r.defectLocation,
      },
    ]
  })

  // 2) Tracer assignments — for each rejected, pick up to 2 unexamined welds
  //    from same welder, same NDE category, not already in batch as accepted/in-progress
  const existingT1ByWelder = new Set(
    (batch.tracerSelections ?? []).filter((t) => t.level === "T1").map((t) => t.sourceRejectedWeldId),
  )
  const tracerAssignments: CascadeOutcome["tracerAssignments"] = rejectedResults.flatMap((r) => {
    const batchWeld = batch.welds.find((w) => w.id === r.weldId)
    if (!batchWeld) return []
    // Pick 2 candidate welds: same welder, not the rejected one, not in current batch
    const inBatch = new Set(batch.welds.map((w) => w.id))
    const candidates = sourceWelds
      .filter((w) => w.welderCode === batchWeld.welder && !inBatch.has(w.id))
      .slice(0, 2)
      .map((w) => w.id)
    // Determine level: if no T1 for this source yet → "T1"; if T1 exists but this is a re-reject → second level
    const isResumeAfterT1Reject = existingT1ByWelder.has(r.weldId)
    const level: TracerSelection["level"] = isResumeAfterT1Reject ? "T1-1" : "T1"
    return [{ sourceRejectedWeldId: r.weldId, candidateWeldIds: candidates, level }]
  })

  // 3) Penalty Shoot detection
  const totalRejections =
    batch.welds.filter((w) => w.result === "Rejected").length + rejectedResults.length
  const has2ndLevelTracer = (batch.tracerSelections ?? []).some(
    (t) => t.level === "T1-1" || t.level === "T1-2" || t.level === "T2-1" || t.level === "T2-2",
  ) || tracerAssignments.some((t) => t.level === "T1-1" || t.level === "T1-2" || t.level === "T2-1" || t.level === "T2-2")

  let penaltyShootTriggered = false
  let penaltyShootReason: CascadeOutcome["penaltyShootReason"] = null
  if (totalRejections >= 4) {
    penaltyShootTriggered = true
    penaltyShootReason = "FOUR_REJECTIONS"
  } else if (has2ndLevelTracer) {
    penaltyShootTriggered = true
    penaltyShootReason = "SECOND_LEVEL_TRACER"
  }

  // 4) SS-eligible welds — same welder × NDE category as batch's primary welder, not already in batch
  let ssEligibleWeldIds: string[] = []
  if (penaltyShootTriggered) {
    // Use the welder of the first rejected weld as the "batch welder"
    const batchWelder = batch.welds[0]?.welder
    if (batchWelder) {
      const inBatch = new Set(batch.welds.map((w) => w.id))
      ssEligibleWeldIds = sourceWelds
        .filter((w) => w.welderCode === batchWelder && !inBatch.has(w.id))
        .map((w) => w.id)
    }
  }

  return {
    r1JointsToCreate,
    tracerAssignments,
    penaltyShootTriggered,
    penaltyShootReason,
    ssEligibleWeldIds,
  }
}

/**
 * Build an R1/R2/Rn joint id given parent jointNo.
 * Naming follows #4 verbatim: "J-1029" → "J-1029-R1" → "J-1029-R2".
 */
export function buildRnJointNo(parentJointNo: string): string {
  const match = parentJointNo.match(/^(.*?)-R(\d+)$/)
  if (match) {
    const base = match[1]
    const next = Number(match[2]) + 1
    return `${base}-R${next}`
  }
  return `${parentJointNo}-R1`
}

/**
 * Build a unique weld id for an R1 joint by suffixing the parent.
 */
export function buildRnWeldId(parentWeldId: string): string {
  const match = parentWeldId.match(/^(.*?)-r(\d+)$/i)
  if (match) {
    const base = match[1]
    const next = Number(match[2]) + 1
    return `${base}-r${next}`
  }
  return `${parentWeldId}-r1`
}

export function isSecondLevelTracer(level: TracerSelection["level"]): boolean {
  return level === "T1-1" || level === "T1-2" || level === "T2-1" || level === "T2-2"
}
```

```tsx
    let activePenaltyShoots = 0
    let activeR1 = 0
    const perSub = new Map<string, { accepted: number; rejected: number }>()
    const perWelder = new Map<string, { accepted: number; rejected: number }>()

    for (const b of batches) {
      if (b.history.some((h) => h.title === "PENALTY SHOOT triggered") && b.status !== "Closed") {
        activePenaltyShoots++
      }
      for (const w of b.welds) {
        if (w.category === "NDE100" && w.parentWeldId && b.status !== "Closed") {
          activeR1++
        }
        const subEntry = perSub.get(b.subcontractor) ?? { accepted: 0, rejected: 0 }
        const welderEntry = perWelder.get(w.welder) ?? { accepted: 0, rejected: 0 }
        if (w.result === "Accepted") {
          subEntry.accepted++
          welderEntry.accepted++
        } else if (w.result === "Rejected") {
          subEntry.rejected++
          welderEntry.rejected++

        perWelder.set(w.welder, welderEntry)
```
