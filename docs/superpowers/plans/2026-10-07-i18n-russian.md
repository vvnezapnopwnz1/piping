# Russian Interface (i18n) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PipeQC работает на двух языках: английском и русском. Человек выбирает язык в меню пользователя или на экране входа, выбор сохраняется на устройстве. Все тексты интерфейса, включая подписи кодов, причины блокировок, пустые состояния и уведомления, есть на русском.

**Architecture:** Используем `next-intl` 4 без языка в адресе. Язык берётся из cookie `NEXT_LOCALE`, а при первом входе — из языка браузера. Тексты лежат в `messages/<язык>/<область>.json`. Источник — английский файл: если в русском файле ключа нет, показывается английский текст. Ключи типизированы, поэтому опечатка в ключе ломает `typecheck`. Два теста держат перевод полным:
- детектор английских строк в коде переведённых папок;
- проверка совпадения ключей, аргументов и терминов глоссария.

Слой предметной логики (`domain`, `application`) возвращает коды. Подписи к кодам выбирает интерфейс. Это то же правило 4 из `AGENTS.md`, только на клиенте.

**Tech Stack:** Next.js 16.2, React 19, TypeScript 5.7, `next-intl` 4.14.9 (новая зависимость, единственная), `node:test` + `tsx`, TypeScript compiler API для детектора, Playwright (только чтение, снимки).

**Spec:** этот документ: разделы «Зачем», «Решения владельца» и «Глоссарий». Основание — разговор 2026-10-07 о первых продажах. Для пилота у казахстанского субподрядчика монтажа нужен русский интерфейс. Сейчас в `app/`, `modules/`, `components/` нет ни одного `.tsx` с кириллицей.

## Решения владельца (по умолчанию — как ниже; владелец может изменить до запуска)

- **D1. Язык не пишется в адресе.** Выбор хранится в cookie `NEXT_LOCALE` на этом устройстве, срок — год. В профиль пользователя в базе выбор не пишется: бэкенд не меняется. Старые ссылки (`/fabrication?p=…`) продолжают работать.
- **D2. Первый вход.** Если браузер настроен на русский или казахский (`ru*`, `kk*`), интерфейс русский, иначе английский. Явный выбор человека всегда важнее.
- **D3. Переключатель.** Он есть в меню пользователя в верхней панели и под формой входа. Название языка всегда пишется на нём самом: «English», «Русский».
- **D4. Что этот план не переводит:**
  - **Данные из базы.** Номера, коды, названия из справочников, демо-данные SHOWCASE-1.
  - **Тексты ошибок сервера.** Это 303 сообщения `raise exception` в SQL и сообщения из `modules/*/infrastructure`. Переведённым будет заголовок уведомления («Не удалось записать результат»), а исходный текст сервера показывается под ним мелким шрифтом. Перевод самих сообщений — отдельный план: сервер возвращает коды, клиент подставляет подписи (правило 4).
  - **PDF из jsPDF** (`modules/documents/infrastructure/renderers`). Для кириллицы нужен встроенный шрифт. Это отдельный план вместе с русскими формами исполнительной документации.

  HTML-формы печати тест-пакета (`app/testpack/print/*`) переводятся.
- **D5. Казахский язык — не сейчас.** Он добавится третьим набором файлов `messages/kk/*` без изменений кода.
- **D6. Даты.** Даты в формате ISO (`2026-08-24`) остаются как есть, они понятны на обоих языках. Языку следуют только подписи недель в графиках и время событий в Tracking.
- **D7. Термины** — по глоссарию ниже. **Владелец подтвердил его 2026-10-07.** Менять термин после перевода двух тысяч строк дороже, чем до. Если исполнителю не хватает термина, он берёт ближайший по смыслу из глоссария и записывает новый термин в отчёт на утверждение. Сам глоссарий исполнитель не меняет.

**Стиль русского текста:**
- **Регистр.** С заглавной буквы пишется только первое слово.
- **Кнопки.** Глагол в инфинитиве: «Записать», «Сохранить».
- **Обращение.** На «вы» со строчной буквы, без «пожалуйста».
- **Ошибки.** Начинаются с «Не удалось …».
- **Пустые состояния.** Например: «Катушек пока нет.»
- **Буква «ё».** Пишется везде, где она произносится: «ещё», «всё», «отклонён».
- **Длина.** В кнопках, вкладках и заголовках колонок русский текст не длиннее английского больше чем на треть. Где нужно, используются аббревиатуры из глоссария.

## Review Focus

1. **Длинный русский текст в узких местах:** кнопки, вкладки, шкала этапов, заголовки колонок, ширина 390 px. Текст не должен обрезаться без многоточия и подсказки. У страницы нет горизонтальной прокрутки. Проверка — шаг «Снимки» в задачах 4–11: `report.json` → `overflow: false` для страниц `9x-mobile-*`; снимки смотрятся глазами.
2. **Переключение языка посреди работы.** Набранный в форме текст остаётся, открытая катушка остаётся, адрес не меняется. Проверка — задача 1 (поле email на входе) и задача 5 (открытая панель катушки).
3. **Первый вход без cookie.** Браузер на русском или казахском — интерфейс русский. Выбор сохраняется после перезагрузки, выхода и нового входа. Проверка — тесты `resolveLocale` и проверки `curl` в задаче 1.
4. **Поиск и фильтры в таблицах по русским словам.** Ищу «Готова к испытанию» — нахожу эти катушки. Значение колонки для поиска и фильтра равно переведённой подписи, а не коду. Проверка — задачи 5 и 6, шаг «Поиск».
5. **Число и существительное согласованы:** «1 стык», «2 стыка», «5 стыков», «11 стыков», «21 стык». Проверка — тест ветвей `one/few/many/other` (задача 2) и файл на вычитку владельцу со всеми сообщениями с числами (задача 12).

## Как переводить (общая процедура для задач 3–11)

Каждая задача 3–11 выполняет эту процедуру на своём списке файлов.

**1. Ключи.**
- **Область.** Задаёт задача: `fabrication`, `erection`, `nde`…
- **Внутри области** — объект на компонент. Он называется по файлу в camelCase без суффикса `-screen`: `qc-release-screen.tsx` → `fabrication.qcRelease`.
- **Имя ключа** описывает роль строки, а не её текст: `title`, `emptyList`, `recordButton`, `columns.spool`, `errors.recordFailed`.
- **Повторы.** Строка, которая повторяется в нескольких компонентах области, лежит в `<область>.shared`.
- **Общие слова** («Сохранить», «Отмена», «Закрыть», «Поиск») лежат в `common.actions`.

**2. Английское значение — прежняя строка символ в символ.** Исключения допустимы только в трёх случаях, и каждое записывается в отчёт:
- **(а)** сырой код, показанный как текст, получает нормальное слово. Например, «Rft» → «Ready for Test»;
- **(б)** приём с `(s)` или `=== 1 ? "" : "s"` заменяется на ICU-plural;
- **(в)** если у одного кода было два английских написания (например, «To Site» и «To site»), остаётся написание из словаря `domain`.

**3. Без склейки.** Одно предложение — одно сообщение с аргументами: `t("openCount", { count })`. Нельзя писать `` `${count} ` + t("open") ``. Ссылка или жирное слово внутри предложения делается через `t.rich("key", { link: (chunks) => <Link href={…}>{chunks}</Link> })`.

**4. Множественное число.** Сообщение с числом пишется так: `"{count, plural, one {# open weld} other {# open welds}}"`. В русском обязательны ветви `one`, `few`, `many`, `other`: `"{count, plural, one {# открытый стык} few {# открытых стыка} many {# открытых стыков} other {# открытого стыка}}"`.

**5. Данные — аргументы.** Номера, имена и значения из базы передаются как аргументы и не переводятся.

**6. Где взять `t`.**
- **Клиентский компонент:** `const t = useTranslations("fabrication.qcRelease")`.
- **Серверный компонент** (страницы печати): `const t = await getTranslations("testPack.print")`.
- **Определения колонок и другие константы вне компонента** превращаются в функцию, которая принимает `t`:

  ```tsx
  export function spoolColumns(t: ReturnType<typeof useTranslations<"fabrication.columns">>): DataTableColumn<SpoolRow>[] {
    return [{ id: "spool", header: t("spool"), value: (row) => row.spoolNumber }]
  }
  // в компоненте:
  const t = useTranslations("fabrication.columns")
  const columns = useMemo(() => spoolColumns(t), [t])
  ```

- **Значение колонки для поиска и фильтра** (`value:`) возвращает переведённую подпись, а не код (Review Focus 4).

**7. Подписи кодов** берутся из области `codes`, её создаёт задача 3: `const tc = useTranslations("codes")` → `` tc(`fabricationStage.${stage}`) ``. Тип `stage` — объединение кодов, поэтому ключ проверяется типами.

**8. Причина как данные.** Функция в `domain` или `application`, которая возвращает английскую фразу для человека, теперь возвращает объединение кодов. Фразу из кода собирает интерфейс. Пример из задачи 5:

```ts
// modules/construction/application/record-material-check.ts — shared by fabrication and erection
export type Gate<Reason> = { allowed: true; reason: null } | { allowed: false; reason: Reason }

// modules/construction/application/record-erection-progress.ts
export type ErectionGateReason =
  | { code: "derived"; stage: ErectionStage }
  | { code: "no_access" }
  | { code: "record_first"; missing: ErectionStage; stage: ErectionStage }
export type ErectionGate = Gate<ErectionGateReason>
```

```tsx
// modules/construction/ui/erection/erection-gate-reason.ts
export function useErectionGateReason() {
  const t = useTranslations("erection.gate")
  const tc = useTranslations("codes")
  return (reason: ErectionGateReason): string => {
    switch (reason.code) {
      case "derived": return t("derived", { stage: tc(`erectionStage.${reason.stage}`) })
      case "no_access": return t("noAccess")
      case "record_first": return t("recordFirst", { missing: tc(`erectionStage.${reason.missing}`), stage: tc(`erectionStage.${reason.stage}`) })
    }
  }
}
```

Тесты `domain` и `application` проверяют коды (`assert.deepEqual(gate.reason, { code: "record_first", missing: "to_site", stage: "erected" })`), а не английские фразы.

**9. Уведомления и ошибки.** Заголовок переводится, текст сервера идёт описанием:

```ts
toast.error(t("errors.recordFailed"), { description: errorDetail(error) })
```

`errorDetail` — из `@/i18n/format` (задача 3). Поле ошибки в форме показывает переведённую фразу и, если он есть, текст сервера второй строкой.

**10. Тесты, читающие исходник.** Тест, который искал английскую строку в `.tsx`, теперь ищет ключ в `.tsx` и английскую строку в `messages/en/<область>.json`. Смысл проверки сохраняется. Удалять такие тесты нельзя.

**11. Исключение из детектора** ставится комментарием `// i18n-ignore — <причина>` (в JSX: `{/* i18n-ignore — <причина> */}`) на строке со строкой или над ней. Допустимые причины: название языка на нём самом, торговое название, текст для разработчика, который человек не увидит. Каждое исключение указывается в отчёте задачи.

```ts
export const LOCALES = ["en", "ru"] as const
export type Locale = (typeof LOCALES)[number]

export const DEFAULT_LOCALE: Locale = "en"
export const LOCALE_COOKIE = "NEXT_LOCALE"

// i18n-ignore — each language is named in itself
export const LOCALE_NAMES: Record<Locale, string> = { en: "English", ru: "Русский" }

/**
 * The language of one request: the person's saved choice, else the first language of the browser
 * that PipeQC speaks. Kazakh browsers get Russian, the language of Kazakh construction sites.
 */
export function resolveLocale(saved: string | undefined, acceptLanguage: string | null): Locale {
  if (saved === "en" || saved === "ru") return saved
  for (const part of (acceptLanguage ?? "").split(",")) {
    const base = part.split(";")[0].trim().toLowerCase().split("-")[0]
    if (base === "ru" || base === "kk") return "ru"
    if (base === "en") return "en"
  }
  return DEFAULT_LOCALE
}
```

```ts
import enCommon from "@/messages/en/common.json"
import ruCommon from "@/messages/ru/common.json"

import type { Locale } from "./locale"

export type MessageTree = { [key: string]: string | MessageTree }

/**
 * English is the source: a key exists here first. Each translation task registers its namespace
 * in both objects below.
 */
export const en = {
  common: enCommon,
}

export type Messages = typeof en
export type Namespace = keyof Messages

/** Russian may lag behind English; a missing key falls back to English (see `mergeMessages`). */
export const ru: { [N in Namespace]?: MessageTree } = {
  common: ruCommon,
}

/** `base` with every key `override` has in the same shape; stray or misshapen keys are dropped. */
export function mergeMessages(base: MessageTree, override: MessageTree | undefined): MessageTree {
  if (!override) return base
  const merged: MessageTree = { ...base }
  for (const [key, value] of Object.entries(override)) {
    const current = base[key]
    if (current === undefined) continue
    if (typeof current === "string") {
      if (typeof value === "string") merged[key] = value
    } else if (typeof value !== "string") {
      merged[key] = mergeMessages(current, value)
    }
  }
  return merged
}

export function messagesFor(locale: Locale): Messages {
  if (locale === "en") return en
  return mergeMessages(en as unknown as MessageTree, ru as MessageTree) as unknown as Messages
}
```

```ts
// scripts/i18n/find-ui-literals.ts
import { readdirSync, readFileSync, statSync } from "node:fs"
import { join } from "node:path"
import ts from "typescript"

export interface UiLiteral {
  file: string
  line: number
  text: string
}

/** JSX attributes a person reads or hears. Every other attribute is markup. */
const TEXT_ATTRIBUTES = new Set([
  "title", "placeholder", "aria-label", "aria-description", "aria-valuetext", "alt", "label",
  "description", "detail", "emptyMessage", "tooltip", "subtitle", "heading", "completedLabel",
])

/** Calls whose string arguments are never shown: class names, keys, queries, logging, errors. */
const SILENT_CALLS = new Set([
  "cn", "clsx", "cva", "twMerge", "t", "useTranslations", "getTranslations", "require",
  "select", "from", "eq", "neq", "in", "is", "order", "rpc", "match", "getItem", "setItem",
  "removeItem", "querySelector", "querySelectorAll", "addEventListener", "removeEventListener",
  "split", "join", "replace", "startsWith", "endsWith", "includes", "padStart", "padEnd",
  "get", "set", "has", "delete", "append", "test", "push", "Error", "TypeError", "RangeError",
])

/** Product names that read the same in every language. */
const NAMES = new Set(["PipeQC", "SpoolGen"])

/** A Tailwind-like token: lowercase, digits and the punctuation class names use. */
const CSS_TOKEN = /^[!a-z0-9[\]&>_:/.%()=,'#*+-]+$/

/** Text a person reads: a sentence, or one capitalised word. Codes, keys and class lists are not. */
export function looksLikeProse(raw: string): boolean {
  const text = raw.replace(/\s+/g, " ").trim()
  if (!/[A-Za-z]{2,}/.test(text) || NAMES.has(text)) return false
  const tokens = text.split(" ")
  if (tokens.every((token) => CSS_TOKEN.test(token)) && tokens.some((token) => /[-:[]/.test(token))) return false
  if (tokens.length > 1) return true
  return /^[A-Z][a-z]/.test(text)
}

function calleeName(expression: ts.Expression): string {
  if (ts.isIdentifier(expression)) return expression.text
  if (ts.isPropertyAccessExpression(expression)) return expression.name.text
  return ""
}

function isConsole(expression: ts.Expression): boolean {
  return ts.isPropertyAccessExpression(expression) && ts.isIdentifier(expression.expression) && expression.expression.text === "console"
}

const COMPARISONS = new Set([
  ts.SyntaxKind.EqualsEqualsEqualsToken, ts.SyntaxKind.ExclamationEqualsEqualsToken,
  ts.SyntaxKind.EqualsEqualsToken, ts.SyntaxKind.ExclamationEqualsToken, ts.SyntaxKind.InKeyword,
])

/** Positions where a string is code, not text: imports, types, keys, comparisons, markup, silent calls. */
function isSilentPosition(node: ts.Node): boolean {
  const parent = node.parent
  if (ts.isImportDeclaration(parent) || ts.isExportDeclaration(parent) || ts.isExternalModuleReference(parent)) return true
  if (ts.isLiteralTypeNode(parent) || ts.isExpressionStatement(parent) || ts.isCaseClause(parent)) return true
  if ((ts.isPropertyAssignment(parent) || ts.isPropertySignature(parent) || ts.isEnumMember(parent)) && parent.name === node) return true
  if (ts.isComputedPropertyName(parent)) return true
  if (ts.isElementAccessExpression(parent) && parent.argumentExpression === node) return true
  if (ts.isBinaryExpression(parent) && COMPARISONS.has(parent.operatorToken.kind)) return true
  for (let current: ts.Node = node; current.parent; current = current.parent) {
    const up = current.parent
    if (ts.isJsxAttribute(up)) return !TEXT_ATTRIBUTES.has(up.name.getText())
    if (ts.isJsxElement(up) || ts.isJsxSelfClosingElement(up) || ts.isJsxFragment(up)) return false
    if ((ts.isCallExpression(up) || ts.isNewExpression(up)) && up.arguments?.some((argument) => argument === current)) {
      return SILENT_CALLS.has(calleeName(up.expression)) || isConsole(up.expression)
    }
    if (ts.isTaggedTemplateExpression(up)) return true
    if (ts.isFunctionLike(up) || ts.isSourceFile(up)) return false
  }
  return false
}

export function findUiLiteralsInSource(file: string, source: string): UiLiteral[] {
  const sourceFile = ts.createSourceFile(file, source, ts.ScriptTarget.Latest, true, file.endsWith(".tsx") ? ts.ScriptKind.TSX : ts.ScriptKind.TS)
  const lines = source.split("\n")
  const found: UiLiteral[] = []
  const report = (position: number, text: string) => {
    const line = sourceFile.getLineAndCharacterOfPosition(position).line
    if (lines[line]?.includes("i18n-ignore") || lines[line - 1]?.includes("i18n-ignore")) return
    if (looksLikeProse(text)) found.push({ file, line: line + 1, text: text.replace(/\s+/g, " ").trim() })
  }
  const visit = (node: ts.Node): void => {
    if (ts.isJsxText(node)) {
      report(node.getStart(sourceFile) + (node.text.length - node.text.trimStart().length), node.text)
    } else if ((ts.isStringLiteral(node) || ts.isNoSubstitutionTemplateLiteral(node)) && !isSilentPosition(node)) {
      report(node.getStart(sourceFile), node.text)
    } else if (ts.isTemplateExpression(node) && !isSilentPosition(node)) {
      report(node.getStart(sourceFile), node.head.text + node.templateSpans.map((span) => `0${span.literal.text}`).join(""))
    }
    ts.forEachChild(node, visit)
  }
  visit(sourceFile)
  return found
}

/** Every `.ts`/`.tsx` file under `paths` (files or folders, relative to `root`), tests excluded. */
export function findUiLiterals(paths: readonly string[], root = process.cwd()): UiLiteral[] {
  const files: string[] = []
  const collect = (path: string) => {
    if (statSync(join(root, path)).isDirectory()) {
      for (const entry of readdirSync(join(root, path))) collect(join(path, entry))
    } else if (/\.tsx?$/.test(path) && !/\.test\.tsx?$/.test(path) && !path.endsWith(".d.ts")) {
      files.push(path)
    }
  }
  paths.forEach(collect)
  return files.flatMap((file) => findUiLiteralsInSource(file, readFileSync(join(root, file), "utf8")))
}
```

```ts
  const flat = new Map<string, string>()
```

```ts
import type { Locale } from "./locale"

/** "Aug 24" / "24 авг." for a week that starts on an ISO calendar date; UTC keeps the day. */
export function formatWeekLabel(isoDate: string, locale: Locale): string {
  return new Intl.DateTimeFormat(locale, { month: "short", day: "numeric", timeZone: "UTC" }).format(new Date(`${isoDate}T00:00:00Z`))
}

/** A moment such as a scan or an upload, in the viewer's own clock. */
export function formatMoment(iso: string, locale: Locale): string {
  return new Intl.DateTimeFormat(locale, { dateStyle: "short", timeStyle: "short" }).format(new Date(iso))
}

/**
 * The server's own words, shown under a translated title. Server messages stay English until the
 * server returns codes (separate plan); an empty message adds nothing.
 */
export function errorDetail(error: unknown): string | undefined {
  const message = error instanceof Error ? error.message : typeof error === "object" && error !== null && "message" in error ? (error as { message: unknown }).message : undefined
  return typeof message === "string" && message.trim() ? message : undefined
}
```

```ts
import { en, ru, type MessageTree } from "@/i18n/messages"

function flatten(tree: MessageTree, prefix = ""): [string, string][] {
  return Object.entries(tree).flatMap(([key, value]) => {
    const path = prefix ? `${prefix}.${key}` : key
    return typeof value === "string" ? [[path, value] as [string, string]] : flatten(value, path)
  })
}

const russian = new Map(flatten(ru as MessageTree))
const rows = flatten(en as unknown as MessageTree)
const cell = (text: string) => text.replace(/\|/g, "\\|").replace(/\n/g, " ")
console.log("# Вычитка русского интерфейса\n")
```
