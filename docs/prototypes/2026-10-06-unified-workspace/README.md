# PipeQC — автономные UX-прототипы

Кандидат D создан Claude после вариантов A/B/C от Gemini. Основное приложение, Supabase и реальные данные не изменены. Все числа и команды записи иллюстративные.

Запуск из корня репозитория:

```sh
node docs/prototypes/2026-10-06-unified-workspace/server.mjs
```

Открыть http://127.0.0.1:4178/review/index.html — сравнение; /d/index.html — итоговый кандидат. Сервер слушает только loopback и отдаёт только статические файлы этих прототипов.

Проверка структуры: `node docs/prototypes/2026-10-06-unified-workspace/verify.mjs a b c d`. Это не браузерная приёмка. Независимые browser smoke checks описаны в acceptance-checklist.md; обоснование выбора — d/decision.md.

Reload сохраняет проект/экран из URL, но сбрасывает симулированные бизнес-данные. Help preferences сохраняются отдельно. Engineering/Tracking и полный производственный workflow вне прототипа.

Следующий этап — просмотр пользователем и согласование модели; переносить всю сборку в рабочий UI автоматически не следует.
