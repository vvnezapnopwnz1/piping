# Демо-проект PCF-1 — порядок загрузки

1. Настройка проекта → Описание: создать проект PCF-1 (код, название, заказчик, подрядчик — лист «Ввести вручную»).
2. В терминале: npm run demo:project-setup -- --project PCF-1 --phase references --dataset pcf
3. Настройка проекта → Импорт: файлы imports/01…05 по порядку.
4. Спулинг → Импорт → источник PCF: все файлы pcf/*.pcf сразу, PDS-зона A-100, настройки по умолчанию.
5. Test Packs → Импорт состава: imports/06-test-packs.xlsx.

PCF переносит только стыки: номер, место (цех/поле), тип, диаметр, катушку, класс, ревизию и ISO.
Трубного материала, опор и болтов в PCF нет, поэтому у катушек этого проекта их не будет; толщину стенки по правилу из imports/04-thickness.xlsx подставляет сервер.
Недели (demo:week) для этого проекта не выполняются.

Начало проекта: 2026-08-28.
